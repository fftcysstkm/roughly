# Roughly

「最後に実施した日」と「次回までの間隔」から、日用品の交換や定期作業をざっくり管理するリマインダーアプリです。

## 開発環境

- Node.js 20.19.4以上
- Expo SDK 57
- React Native / TypeScript / Expo Router

## セットアップ

```sh
npm install
npm start
```

型チェックとLintは次のコマンドで実行します。

```sh
npm run typecheck
npm run lint
```

詳細な仕様は [`docs/REQUIREMENTS.md`](docs/REQUIREMENTS.md) を参照してください。
